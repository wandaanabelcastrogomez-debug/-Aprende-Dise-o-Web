Descripción de la aplicación: Aprende Diseño Web
Aprende Diseño Web es una aplicación educativa diseñada para enseñar a principiantes a crear y diseñar páginas web desde cero, utilizando los lenguajes de programación HTML, CSS y JavaScript.

La aplicación ofrece lecciones explicadas paso a paso, ejemplos de códigos, ejercicios prácticos y evaluaciones para facilitar el aprendizaje.

Su objetivo principal es que los estudiantes desarrollen habilidades para crear páginas web modernas, atractivas, organizadas e interactivas, sin necesidad de tener conocimientos previos de programación.

Características principales:
- HTML: aprender a crear la estructura de una página web.
- CSS: diseñar páginas con colores, imágenes, botones y estilos.
- JavaScript: agregar funciones, interactividad y acciones.
- Prácticas: escribir y ejecutar códigos para observar los resultados.
- Exámenes: evaluar los conocimientos adquiridos.
- Glosario: consultar conceptos importantes del diseño web.
- Seguimiento: registrar las lecciones completadas.
Público al que está dirigida: estudiantes, principiantes y personas interesadas en aprender diseño y desarrollo web.

Objetivo general: proporcionar una herramienta de aprendizaje sencilla, práctica e interactiva que permita adquirir conocimientos básicos de diseño web y desarrollar proyectos propios.
